# Your intent to file a VA claim

Official: https://www.va.gov/resources/your-intent-to-file-a-va-claim/
Publisher: U.S. Department of Veterans Affairs
Snapshot date: 2026-09-19 (page last updated August 17, 2026 per VA.gov)

An intent to file sets a potential effective date. If VA later approves the claim, retroactive payments may run from the intent-to-file date rather than the completed-claim date.

Applies to disability compensation, pension, and DIC / survivors pension pathways.

## Rules VA publishes

- After you notify VA of the intent to file, you have 1 year to complete and file the claim.
- You can have only 1 active intent to file at a time.
- After the completed claim is filed, that intent to file is no longer active for other claims.
- A new intent to file is needed if the first one was for a different benefit type (compensation vs pension).

## How to submit

Online; by phone; in person; or VA Form 21-0966 by mail. An accredited VSO, claims agent, or attorney can help submit it.

Post volunteers should record whether an ITF is already on file before assembling a packet so the accredited officer does not miss the one-year clock.
